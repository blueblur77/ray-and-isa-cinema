Google Sheet Connection & Poster Settings

Connect your Ray and Isa Movie Catalog sheet (18dMxzqimum6c4KfF7TgD0wZfmqXbjCYTAxxGHoTxvCg) so the website reads live requests, adds the Watched & Poster URL columns automatically, and saves changes back to the sheet.

1
Open your Google Sheet and click Extensions → Apps Script.
2
Paste the code from google_apps_script.gs into Code.gs and save.
3
Click Deploy → New deployment → Web app, set Execute as to Me and Who has access to Anyone, then copy the https://script.google.com/macros/s/.../exec URL from the deploy dialog (or Deploy → Manage deployments) — not the temporary browser script.googleusercontent.com/macros/echo redirect link.
Use your permanent /exec Web App URL so live reading, 1-click Watched updates, and Poster URL saving work across refreshes.
